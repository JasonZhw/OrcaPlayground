## 当前流程

`main.py` 统一启动；`workflow.py` 读取场景、计算抓取目标并编排任务；`planning.py` 用多初值IK与RRT-Connect求解避碰路径；`execution.py` 驱动机器人；`recording.py` 同步记录相机、状态、动作及英文任务。

左臂负责两只药瓶入左紫框，右臂负责两只药盒入右蓝框，两臂交替执行。专家读取仿真中的目标位姿，不依赖相机识别，也未使用CuRobo。物品只在初始化时设置摆放，搬运由真实仿真接触完成；规划模型中的携带假设不会把物品焊接到执行中的夹爪上。

物理参数每次运行时应用：固定底盘，指尖 `condim=6`、全局 `impratio=2`，排除已确认的四连杆内部碰撞；保留对物体、对向指尖及环境的接触。无需修改订阅资产或虚拟环境包。

## 运动与释放

- 路径时间采样采用五次平滑曲线。常规关节指令速度上限0.4rad/s、加速度上限0.8rad/s²；下放和撤回分别降到0.2rad/s、0.4rad/s²。
- 相邻阶段从上一条关节指令继续，避免跟踪误差造成指令跳变。初始接触预载在录制前平滑消除，最多3次，仍有碰撞则停止。
- 入框XY按物体轮廓限制在框底范围内并留8mm边距。释放时药瓶底部距框底约8cm，药盒约5cm；该场景药瓶降到5cm时侧抓手腕会碰框沿。
- 先保持夹紧下放，到位后停留，再用1.2秒逐渐松爪，等待0.5秒后撤回。实际目标保存在 `placement_targets.json`。
- 碰撞路径的中间路点仍会减速到零，抓持和到位阶段保留停顿，规划也可能需要等待；不承诺全程无停顿。

## 数据与夹爪接口

原始格式为 `medication_sorting_raw_v2`。每帧状态30维：左臂7＋左夹爪实测关节8＋右臂7＋右夹爪实测关节8；动作原生16维：左臂7＋左夹爪1＋右臂7＋右夹爪1。关节单位为弧度，状态和动作维度不同是正常的。

每只夹爪输出0～1的标定闭合指令：0张开、1完整夹持。它表示指令进度，不是实测宽度或力，也不能直接当作内部d。控制器保持上一条指令，直到明确更新；底层使用 `medication_closure_v1` 映射，节点间线性插值：

| 闭合指令 | 内部a | 内部d |
|---|---:|---:|
| 0 | 0 | -1 |
| 0.4 | 0 | 0.97 |
| 0.7 | 0.28 | 0.90 |
| 1 | 0.28 | 1.45 |

模型推理必须沿用相同映射。LeRobot导出只整理文件、视频编码与任务关联，不做18维到16维转换；旧18维数据会被拒绝。

头部、左右腕三路相机各640×480，不裁剪、不缩放。执行前状态与动作对应同一仿真索引的图像，仿真时间每步推进0.02秒。录制等待三路图像、解码和写盘完成后才继续仿真，因此墙钟录制时间长于视频按50Hz播放的时长。
